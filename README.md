# Tkinter-calculator-
Features
Add, subtract, multiply, divide
Percent of a total, square, and square root
Calculation history (show and clear)
Input validation: rejects text, nan, and inf
Clear error messages for division by zero, negative square roots, and results that are too large
Requirements
Python 3.8 or newer. No extra packages needed.

How to run
python calculator.py
Example session
=== Calculator ===
